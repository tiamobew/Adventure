# คู่มือเชื่อมเกมกับ Google Sheet (สำหรับมือใหม่)

เกม `part2.html` เชื่อมกับ Google ได้ 2 อย่าง:

1. **โหลดโจทย์จาก Google Sheet** — ครูพิมพ์/แก้โจทย์ในตารางได้เอง ไม่ต้องแตะโค้ด
2. **บันทึกคะแนนผู้เล่นลง Google Sheet** — ทุกครั้งที่จบเกม (ชนะ/แพ้) ระบบบันทึกชื่อ คะแนน เวลา ให้อัตโนมัติ
3. **ซิงก์หน้า Admin ทุกอุปกรณ์** — ครูเพิ่ม แก้ ปิดใช้ หรือลบโจทย์จากหน้า Admin แล้วผู้เล่นทุกเครื่องจะใช้ข้อมูลชุดเดียวกัน

> เปิดไฟล์ `part2.html` เฉยๆ (ดับเบิลคลิก) ก็ **เล่นได้ทันที** — แค่จะใช้โจทย์สุ่มอัตโนมัติ และยังไม่บันทึกคะแนน
> ถ้าอยากได้ฟีเจอร์เชื่อมต่อทั้งหมดข้างบน ให้ทำตาม**วิธี A** ด้านล่าง (แนะนำสำหรับมือใหม่)

---

## 🟢 วิธี A — เอาเกมไปไว้บน Google (แนะนำ ง่ายสุด ครบสุด)

ทำครั้งเดียว ได้ทั้งลิงก์เล่นเกม + โหลดโจทย์จากชีท + บันทึกคะแนน ในที่เดียว

### ขั้นที่ 1 — สร้าง Google Sheet
1. เข้า https://sheets.google.com แล้วสร้างสเปรดชีตใหม่ 1 อัน
2. ตั้งชื่อไฟล์ตามใจ เช่น `เกมทศนิยม-คะแนน`

### ขั้นที่ 2 — เปิดตัวเขียนสคริปต์
1. ในสเปรดชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. จะเปิดหน้าต่างเขียนโค้ดขึ้นมา มีไฟล์ชื่อ `Code.gs` อยู่แล้ว

### ขั้นที่ 3 — วางโค้ด Code.gs
1. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้งทั้งหมด
2. เปิดไฟล์ `apps-script/Code.gs` คัดลอกทั้งหมดไปวางแทน
3. กดรูปแผ่นดิสก์ 💾 (บันทึก)

### ขั้นที่ 4 — เพิ่มไฟล์หน้าเกมและหน้า Admin
1. ข้างคำว่า "ไฟล์ (Files)" กดปุ่ม **+ → HTML**
2. ตั้งชื่อไฟล์ว่า **`part2`** (ระบบจะเติม `.html` ให้เอง — ห้ามพิมพ์ผิดชื่อ เพราะโค้ดเรียกชื่อนี้)
3. ลบเนื้อหาตัวอย่างในไฟล์ที่เพิ่งสร้างออกให้หมด
4. เปิดไฟล์ `part2.html` ที่ root ของโปรเจกต์ คัดลอก**ทั้งหมด**ไปวาง
5. กดบันทึก 💾
6. ทำซ้ำอีกครั้ง: สร้างไฟล์ HTML ชื่อ **`admin`** แล้วคัดลอกเนื้อหาจาก `admin.html` ที่ root ไปวาง

### ขั้นที่ 5 — ตั้งรหัส Admin

1. ใน Apps Script กด **การตั้งค่าโปรเจกต์ (Project Settings)** รูปเฟือง
2. ที่ **พร็อพเพอร์ตี้ของสคริปต์ (Script properties)** เพิ่มพร็อพเพอร์ตี้ชื่อ `ADMIN_PIN`
3. ใส่รหัสที่ต้องการใช้เข้าหน้า Admin แล้วกดบันทึก (ไม่ควรใช้รหัสตัวอย่างในโค้ดเมื่อเปิดใช้งานจริง)

### ขั้นที่ 6 — สร้างตารางโจทย์ตัวอย่าง
1. ด้านบนของ Apps Script มีช่องเลือกฟังก์ชัน เลือก **`setupQuestionSheet`**
2. กด **เรียกใช้ (Run)** ▶
3. ครั้งแรกจะขอสิทธิ์ — กด **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชี Google ของคุณ →
   ถ้าขึ้นเตือน "ไม่ได้รับการยืนยัน" ให้กด **ขั้นสูง (Advanced) → ไปที่ ... (unsafe)** → **อนุญาต (Allow)**
   *(ปลอดภัย เพราะเป็นสคริปต์ของคุณเอง)*
4. เสร็จแล้วกลับไปดูที่ Google Sheet จะมีแท็บใหม่ชื่อ **"โจทย์"** พร้อมโจทย์ตัวอย่าง

### ขั้นที่ 7 — เผยแพร่เป็นเว็บแอป (Deploy)
1. มุมขวาบน กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
2. กดรูปเฟือง ⚙ ข้าง "เลือกประเภท" → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า:
   - **ดำเนินการในฐานะ (Execute as):** ตัวฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)**  ← สำคัญ! เพื่อให้นักเรียนเปิดเล่นได้
4. กด **ทำให้ใช้งานได้ (Deploy)** → คัดลอก **ลิงก์เว็บแอป (Web app URL)** เก็บไว้
5. เปิดลิงก์นั้นในเบราว์เซอร์ → **เล่นเกมได้เลย!** โจทย์จะมาจากชีท และคะแนนจะถูกบันทึกอัตโนมัติ
6. หน้า Admin เปิดได้โดยเติม `?page=admin` ต่อท้ายลิงก์เว็บแอป เช่น `.../exec?page=admin`

> ✅ ในหน้าเริ่มเกมจะเห็นข้อความ **"✅ ใช้โจทย์จาก Google Sheet (… ข้อ)"** = เชื่อมสำเร็จ

## ✏️ วิธีแก้ไขโจทย์ (ส่วนที่ครูใช้บ่อย)

วิธีที่สะดวกที่สุดคือเปิด `.../exec?page=admin` แล้วเพิ่ม/แก้/ปิดใช้โจทย์ จากนั้นกดบันทึก การเปลี่ยนแปลงจะอยู่ใน Google Sheet และมีผลกับทุกอุปกรณ์เมื่อเปิดหรือกลับมาที่หน้าเกม (หน้าที่เปิดค้างไว้จะตรวจโจทย์ใหม่อัตโนมัติภายใน 1 นาที)

หน้า Admin ใช้ไฟล์ **CSV** สำหรับย้ายคลังโจทย์:

- กด **ส่งออก CSV** เพื่อสำรองหรือเปิดแก้ไขใน Excel/Google Sheets
- กด **นำเข้า CSV** เพื่ออัปโหลดกลับเข้าคลังกลาง
- คอลัมน์มาตรฐานคือ `id,level,enabled,text,answer,choices,hint`
- ตัวเลือกหลายคำตอบในคอลัมน์ `choices` คั่นด้วย `|` เช่น `3.8|3.2|4.8|2.8`
- ดูตัวอย่างพร้อมใช้ได้ที่ไฟล์ `questions-template.csv`

ถ้าต้องการแก้ในชีทโดยตรง ตารางรุ่นใหม่มีคอลัมน์ `id`, `ระดับ`, `เปิดใช้`, `โจทย์`, `คำตอบ`, `ตัวเลือก`, `คำใบ้` (ระบบยังอ่านชีทเดิมแบบ 3 คอลัมน์ได้)

ตัวอย่างข้อมูลหลัก:

| ระดับ | โจทย์ | คำตอบ |
|-------|-------|-------|
| ง่าย | 1.5 + 2.3 | 3.8 |
| ปานกลาง | 2.5 × 4 | 10.0 |
| ยาก | 3.2 + (1.5 × 2) | 6.2 |
| บอส | (6.0 × 3) - 2.5 | 15.5 |

**กติกาการพิมพ์:**
- **ระดับ** พิมพ์ได้ 4 แบบ: `ง่าย` `ปานกลาง` `ยาก` `บอส` (หรือ `easy` `medium` `hard` `boss`)
- **โจทย์** พิมพ์แค่ตัวโจทย์ ไม่ต้องใส่ `= ?` (ระบบเติมให้เอง) ใช้เครื่องหมาย `+  -  ×  ÷` ได้
- **คำตอบ** ใส่ตัวเลขคำตอบที่ถูกต้อง (เกมยอมคลาดเคลื่อนได้ ±0.05 กันปัญหาปัดเศษ)
- โจทย์ที่มีหลายเครื่องหมาย **แนะนำใส่วงเล็บ** เช่น `3.2 + (1.5 × 2)` ให้ชัดว่าคิดส่วนไหนก่อน
- เพิ่มกี่ข้อก็ได้ในแต่ละระดับ เกมจะสุ่มหยิบมาใช้ให้เอง
- แก้เสร็จแล้ว **รีเฟรชหน้าเกม** ก็ใช้โจทย์ใหม่ทันที (ไม่ต้อง Deploy ใหม่)

> ในแต่ละด่าน: ง่าย 3 ตัว → ปานกลาง 3 ตัว → ยาก 3 ตัว → บอส 1 ตัว รวม 10 ตัว และมีทั้งหมด 3 ด่าน
> ควรมีโจทย์อย่างน้อยระดับละ 1 ข้อ (ถ้าระดับไหนไม่มีในชีท เกมจะสุ่มโจทย์ให้อัตโนมัติเฉพาะระดับนั้น)

## 🔵 วิธี B — เปิดไฟล์ HTML แยก แล้วส่งคะแนนเข้าชีท (สำหรับคนที่อยากวางเกมบนเว็บอื่น)

ถ้าคุณอยากวาง `part2.html` ไว้ที่อื่น (เช่น GitHub Pages) แต่ยังอยากบันทึกคะแนน/โหลดโจทย์:

1. ทำ **ขั้นที่ 1–7 ของวิธี A** ให้ครบก่อน (เพื่อให้ได้ลิงก์เว็บแอป)
2. เปิดไฟล์ `js/config.js`
3. วางลิงก์เว็บแอปที่ได้ใน `webAppUrl` เช่น:
   ```js
   window.SKYISLAND_CONFIG = {
     webAppUrl: 'https://script.google.com/macros/s/xxxxxxxx/exec'
   };
   ```
4. บันทึกไฟล์ แล้วเอาไปวางบนเว็บที่ต้องการ

> หน้าเกมบน GitHub Pages จะอ่านโจทย์จากลิงก์นี้ ส่วนการจัดการโจทย์กลางให้ใช้หน้า Admin ของ Apps Script (`.../exec?page=admin`) เพื่อไม่เปิดเผยสิทธิ์เขียนข้อมูลในเว็บสาธารณะ

> หมายเหตุ: วิธี B การบันทึกจะเป็นแบบ "ส่งแล้วไม่รอผลตอบกลับ" (no-cors) ปกติบันทึกได้ แต่จะไม่แสดง ✅ ยืนยันเป๊ะๆ
> ถ้าไม่จำเป็น แนะนำใช้ **วิธี A** จะชัวร์และง่ายกว่า

## ❓ แก้ปัญหาที่พบบ่อย

- **หน้าเริ่มเกมยังขึ้น "🎲 ใช้โจทย์สุ่มอัตโนมัติ"** → ยังไม่ได้เชื่อมชีท หรือแท็บ "โจทย์" ว่าง/สะกดชื่อผิด
- **เปิดลิงก์แล้วจอเปล่า** → ตรวจว่าไฟล์ HTML ใน Apps Script ชื่อ `part2` (ไม่ใช่ `Code` หรือชื่ออื่น)
- **นักเรียนเปิดลิงก์ไม่ได้** → ตอน Deploy ต้องตั้ง "ผู้ที่มีสิทธิ์เข้าถึง" เป็น **ทุกคน (Anyone)**
- **แก้โค้ด/โจทย์แล้วไม่อัปเดต** → แก้ *โจทย์ในชีท* แค่รีเฟรชหน้าเว็บ / แต่ถ้าแก้ *โค้ดหรือ part2.html* ต้อง Deploy ใหม่
  (Deploy → จัดการการทำให้ใช้งานได้ → ✏ แก้ไข → เวอร์ชันใหม่ → Deploy)
