# Google Apps Script

โฟลเดอร์นี้เก็บ backend สำหรับคลังโจทย์กลางและการบันทึกคะแนน

- คัดลอก `Code.gs` ไปยัง Apps Script project ที่ผูกกับ Google Sheet
- หน้า HTML ที่ต้องเพิ่มใน Apps Script คือ `part2.html` และ `admin.html` จาก root ของ repository
- ขั้นตอนติดตั้งและ Deploy อยู่ที่ [`../docs/google-sheet-setup.md`](../docs/google-sheet-setup.md)

ไฟล์หน้าเว็บยังคงอยู่ที่ root เพื่อให้ GitHub Pages ใช้งาน URL เดิมได้โดยไม่กระทบผู้เล่น
