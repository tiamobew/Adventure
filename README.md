เกมกระดานแบบบันไดงู 3D บนเกาะลอยฟ้า สำหรับผู้เล่น 2-4 คน
ตอบโจทย์ปัญหาทศนิยมระดับประถม (ป.6) ถูก → ทอยลูกเต๋าเดินหน้า
ตอบผิดหรือหมดเวลา → หยุดเดิน 1 ตา ใครถึงช่องสุดท้ายก่อนชนะ

**ฟีเจอร์ล่าสุด:**
- กลับไปใช้โจทย์ทศนิยม (จากเวอร์ชันจำนวนเต็ม ป.2-3) ตามด่านที่ระบุ:
  ง่าย = ทศนิยม 1 หลัก 1 ขั้นตอน, ปานกลาง = ทศนิยม 2 หลัก 2 ขั้นตอน,
  ยาก = ทศนิยม 2 หลัก 3 ขั้นตอน
- แก้บั๊กสำคัญ: บางโจทย์ระดับยาก/ปานกลางเคยสุ่มค่าจนคำตอบติดลบได้ ทำให้ระบบ
  หาตัวเลือกตอบผิดไม่ได้และค้าง (infinite loop) — ปรับสูตรให้คำตอบเป็นบวกเสมอ
  พร้อมเพิ่มเพดานจำนวนรอบสุ่ม + ตัวเลือกสำรอง กันเหนียวไม่ให้ค้างอีกในอนาคต
  (ทดสอบสุ่มโจทย์ 5,000 ครั้ง/ด่านแล้ว ไม่พบปัญหา)
- เลือกเวลาต่อคำถามได้ยืดหยุ่นขึ้น: ปุ่มตายตัว (10/15/20/30 วิ), กำหนดเวลาเอง
  (พิมพ์จำนวนวินาทีเอง 5-180 วิ), หรือเลือก "∞ ไม่จำกัดเวลา" ก็ได้
  (โหมดไม่จำกัดเวลาจะไม่มีโบนัสไว แต่ยังได้คะแนนพื้นฐานตามปกติ)
- ตัวเลือกคำตอบ (choices) ขนาดใหญ่ขึ้นชัดเจน อ่านง่ายขึ้นสำหรับเด็กเล็ก
- เปลี่ยนฟอนต์ทั้งเว็บเป็น Sarabun (ใกล้เคียง TH SarabunPSK มากที่สุดในกลุ่ม
  ฟอนต์เว็บของ Google Fonts เนื่องจาก TH SarabunPSK ไม่มีเวอร์ชันเว็บฟอนต์)

**ฟีเจอร์อื่น ๆ ที่มีอยู่แล้ว:** กระดานอันดับคะแนนชัดเจน (🏆 พร้อมเหรียญ 🥇🥈🥉),
เสียงเอฟเฟกต์ตอบถูก/ผิด, เพลงประกอบ, ตั้งชื่อผู้เล่นเอง, ระบบคำใบ้แลกด้วยแต้ม,
ตัวละครน่ารักขนาดใหญ่, ป้ายเลขสีสันประจำช่อง, แบ่งจอ 2 ฝั่ง (คำถาม/ภาพ 3D)

## โครงสร้างไฟล์

```
skyisland/
├── index.html          หน้าเว็บหลัก โครง UI (start screen, HUD, win screen)
├── css/
│   └── style.css        ธีมสี ฟอนต์ ปุ่ม HUD ทั้งหมด
└── js/
    ├── questions.js     คลังโจทย์ทศนิยม + ฟังก์ชันสุ่มโจทย์/ตัวเลือก
    ├── scene.js          ฉาก 3D: เกาะ, ทะเลเคลื่อนไหว, ต้นไม้โยกลม, แสง/กล้อง
    ├── path.js           สร้างเส้นทางบันไดงู (24 ช่อง) บนเกาะ
    ├── game.js           ตรรกะเกม: ผู้เล่น, ตาเดิน, ตรวจคำตอบ, เดินหมาก, ชนะ
    └── main.js           ผูกปุ่ม UI + ลูปแอนิเมชันหลัก (เรียก requestAnimationFrame)
```

สคริปต์เป็น **global script tags ธรรมดา** (ไม่ใช่ ES modules) โหลดตามลำดับใน
`index.html` เพื่อให้เปิดไฟล์ตรง ๆ ในเบราว์เซอร์ได้เลยโดยไม่ต้องรันเซิร์ฟเวอร์

## วิธีทดสอบตอนนี้

เปิด `index.html` ด้วยเบราว์เซอร์ได้ทันที (ดับเบิลคลิก หรือ Live Server ใน VS Code)

## วิธีนำไปต่อยอดด้วย Claude Code

1. ติดตั้ง Claude Code (`npm install -g @anthropic-ai/claude-code`) แล้วรัน `claude`
   ในโฟลเดอร์โปรเจกต์นี้ (`cd skyisland && claude`)
2. Claude Code จะอ่านโครงสร้างไฟล์ทั้งหมดได้เอง ให้บอกสิ่งที่ต้องการต่อ เช่น
   ตัวอย่างคำสั่งที่ใช้ได้:
   - "เพิ่มช่องพิเศษแบบ 'สะพานลัด' และ 'พายุ' บนเส้นทางใน path.js ที่ทำให้เดินข้ามหรือถอยหลัง"
   - "เพิ่มเสียงเอฟเฟกต์ตอนตอบถูก/ผิด และตอนถึงเส้นชัย"
   - "เพิ่มโจทย์ทศนิยมแบบใหม่ใน questions.js เช่น การเปรียบเทียบทศนิยม"
   - "ทำให้กล้องหมุนตามหมากที่กำลังเดินแบบนุ่มนวล (camera follow)"
   - "เพิ่มชื่อผู้เล่นให้พิมพ์เองได้ที่หน้า start screen"
   - "ปรับให้เล่นบนมือถือลื่นขึ้น (ลด waterSegments, ปิด fog บนเครื่องแรงต่ำ)"
3. เพราะโค้ดแยกไฟล์ตามหน้าที่ชัดเจนแล้ว การขอให้ Claude Code แก้ทีละไฟล์
   (เช่น "แก้เฉพาะ scene.js") จะได้ผลลัพธ์แม่นยำกว่าขอแก้ทั้งโปรเจกต์รวด

## จุดต่อยอดที่แนะนำเป็นลำดับถัดไป

- **ช่องพิเศษ**: ใน `path.js` เพิ่ม array `specialTiles = { 5: +3, 12: -2 }` แล้วเช็คใน
  `movePawnSteps` ของ `game.js` ว่าช่องที่ลงมี bonus/penalty หรือไม่
- **เสียง**: ใช้ `<audio>` tag หรือ Web Audio API เพิ่มใน `game.js` ที่ฟังก์ชัน
  `handleAnswer`
- **แยกโจทย์ตามระดับชั้น**: เพิ่ม dropdown เลือกระดับใน start screen แล้วส่งค่า
  ไปกรอง `TEMPLATES` ใน `questions.js`
- **บันทึกคะแนน/สถิติ**: เก็บจำนวนตาที่ตอบถูก/ผิดต่อผู้เล่น แสดงในหน้าจอชนะ

## เทคนิคที่ใช้ (สำหรับอ้างอิงตอนคุยกับ Claude Code)

- Three.js r128 (โหลดจาก CDN, non-module build)
- ทะเล: `PlaneGeometry` ปรับตำแหน่ง vertex ทุกเฟรมด้วยฟังก์ชัน sine/cosine (CPU-based wave)
- ต้นไม้: หมุน `rotation.z/x` เบา ๆ ตาม `Math.sin(t + phase)` ให้แต่ละต้นโยกไม่พร้อมกัน
- เส้นทาง: จัด index แบบ boustrophedon (สลับทิศทุกแถว) แบบกระดานงูจริง
- การเดินหมาก: ขยับทีละช่องด้วย `setTimeout` recursive แทนการ tween ต่อเนื่อง (ง่ายต่อการอ่าน/แก้)
